# Book Look Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the books look like a bound book (cover, cream or dark paper, gold rule, spine shadow, page number, lifted corner), justify their text, and peel the corner once for first-time readers.

**Architecture:** A `BookPaper` setting picks paper colours from new theme tokens. A `BookFrame` widget draws the cover and paper around the page (both modes) and the page-only marks (spine, number, corner) in Pages mode; the paginator gets the box inside it. Justified line ranges are drawn by laying out the whole paragraph once (justified) and painting only the slice's lines. The peel is a `Tip` that drives `PageCurlController.peek()` once.

**Tech Stack:** Flutter 3.47.9, Riverpod 3. No new packages.

**Spec:** `docs/superpowers/specs/2026-11-21-book-look-design.md` (builds on `2026-11-20-book-page-flip-design.md`).

## Global Constraints

- Setting `bookPaper`: `cream` | `dark`, default `cream`, JSON key `"bookPaper"`; unknown/missing → `cream`. Chooser labels exactly "Cream" / "Dark", label "Paper", in the book reader's sheet under the Pages/Scroll chooser.
- The app theme default stays dark; only the book page area uses the paper colours.
- Cream paper: new tokens on `NamoPalette` (same values in light and dark palettes): `bookPaper` 0xFFF7EFDC, `bookInk` 0xFF2A2A22, `bookInkSoft` 0xFF8A7A55, `bookCover` 0xFF5B3A22, `bookRule` 0xFFD2B26C. Dark paper: `bookPaperDark` = palette dark `surface` (0xFF1A241C), `bookInkDark` = dark `text`, `bookCoverDark` 0xFF3A2616, `bookRuleDark` 0x99D2B26C. No raw colours outside tokens.dart.
- Look in both modes: cover, paper colour, gold rule, justified text. Pages mode only: spine shadow on the page's left edge, page number at the foot (the page's 1-based index within the chapter), lifted corner at bottom right.
- Justified: paragraphs and list/footnote item text. Not justified: titles, headings, subheads, gatha, tables, captions. A paragraph's own last line stays ragged; a slice's last line that is not the paragraph's last is justified.
- Line breaks never change: what is drawn breaks exactly where the paginator measured.
- First-time peel: `Tip.bookPeel`; runs once, the first time a book opens in Pages mode with a current page and a next page; lifts to progress 0.15 and back over 1.2 s total; marked seen when it starts; skipped (and still marked seen) when `MediaQuery.disableAnimationsOf` is true; a user drag/tap during the peel cancels it at once; "Show the tips again" (`resetAll`) replays it.
- No overflow at 320×568 with fontScale 1.6, both papers, both themes, both modes. 48-point targets. Saved places keep working. Text never changed.

## Review Focus

1. **Dark paper in the light theme, cream paper in the dark theme** — text and page number stay readable (ink colour comes from the paper, not the theme). (Task 3 test `ink follows the paper, not the theme`.)
2. **Sinhala text with joiners justified** — drawing only some lines of a justified layout never shows parts of neighbouring lines (clip exact to line tops/bottoms). (Task 2 test `a slice shows only its own lines`.)
3. **A drag during the peel** — the peel stops at once and the drag turns normally. (Task 4 test `a drag cancels the peel`.)
4. **The frame at 320 wide with large text** — the frame's insets shrink the page box; nothing overflows. (Task 3 overflow test.)
5. **Switching paper mid-chapter** — the page re-draws in place; no re-cut needed, place kept. (Task 3 test `switching paper keeps the page`.)
